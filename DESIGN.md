## Brand & Style

This design system delivers an executive, high-density workspace tailored for modern print manufacturing, corporate apparel, and multi-tenant branding enterprises. Merging the technical precision of developer tools with the fluid visual aesthetics of tier-one SaaS dashboards, the atmosphere is deep, focused, and deliberate.

### Target Audience & Emotional Intent
- **Audience:** Plant managers, print fulfillment teams, account executives, and corporate client buyers managing complex production queues, material specifications, and financial approvals across multi-tenant instances.
- **Atmosphere:** Rigorous, high-performance, and technologically advanced. It eliminates sensory clutter, instills operational confidence, and renders dense datasets legible under intensive daily workflows.

### Visual Architecture & Movement
- **Style Movement:** Precision Dark Glassmorphism meets High-Density B2B Modernism.
- **Structural Identity:** Dark obsidian-slate backdrops paired with translucent, multi-tiered container surfaces (`#151C24` and `#1A222D`). Surfaces are defined by razor-thin translucent borders (`rgba(255, 255, 255, 0.07)`) and subtle ambient glows.
- **Logomark & Visual Adaptation:** The signature interlocking vector swirl adapts seamlessly to deep dark surfaces. The lighter path renders in luminous cyan (`#00AEFF`), while the dark path flips to clean, bright optic white (`#F8FAFC`) with subtle outer luminance, guaranteeing contrast and brand authority across desktop headers and collapsed navigation rails.

## Colors

The color palette is built for long-duration operator comfort and rapid data parsing. The foundational canvas utilizes an ultra-refined dark obsidian hierarchy (`#0B0F14` through `#1A222D`), avoiding pure black to preserve depth perception and surface separation.

### Functional Roles
- **Primary (`#00AEFF`):** Electric Cyan drives primary calls-to-action, key telemetry trend lines, active tab markers, and focused interactive states.
- **Secondary (`#0284C7`):** Deep Sky Blue serves as a supporting anchor for secondary interaction vectors, subtle data bars, and gradient mid-tones.
- **Tertiary (`#10B981`):** Precision Emerald is reserved for active production confirmations, positive yield variances, and live operational statuses.
- **Neutral (`#0B0F14`):** Obsidian Base establishes deep spatial canvas isolation, anchoring the application shell.

### Status Tonal Tokens
Status chips operate on low-saturation, semi-transparent fills coupled with high-luminance foreground labels and 6px optical indicator pips. Emojis are strictly prohibited; semantic clarity relies solely on disciplined color tokens and crisp vector icons.

## Typography

Typography centers on pure functional clarity through a single, versatile type family (`Inter`), optimized for high data density and clean structural rhythm.

### Tabular Formatting & Hierarchy
- **Financial & Production Figures:** All order volumes, substrate dimensions, print run speeds, and balance amounts must use the `data-tabular` or `data-metric` tokens with OpenType tabular figures enabled (`font-feature-settings: "tnum" 1, "cv05" 1`).
- **Headers & Display:** Headlines utilize tight negative tracking (`-0.03em` to `-0.015em`) with bold optical weights to stand out cleanly against deep background cards.
- **Labels & Micro-data:** Operational table headers and pill chip tags apply uppercase or high-contrast medium weights (`label-sm`) with relaxed letter spacing (`+0.04em`) to ensure legibility across multi-tenant workspace tables.

## Layout & Spacing

The layout employs a high-density, multi-panel structural model optimized for 1440px+ command center resolutions, adapting responsively across tablet and mobile viewports.

### Grid & Layout Rules
- **Application Shell:** A rigid 240px left-hand collapsible rail (`#0B0F14`) sits flush against the active canvas workspace (`#0F1419`).
- **Content Flow:** Standard pages adhere to an adaptable 12-column fluid grid system with `1rem` (16px) gutters and `1.5rem` (24px) canvas outer padding. Metric KPI strips typically utilize 4-column cards spanning 3 units each, or 3-column cards spanning 4 units on wide screens.
- **Adaptive Breakpoints:**
  - **Desktop (>= 1280px):** Persistent sidebar navigation, 4-column metric grids, full side-by-side table and visual preview splits.
  - **Tablet (768px - 1279px):** Sidebar collapses to an icon-only 64px rail, metric grids reflow to 2x2 formations, horizontal table scroll enabled with frozen primary identifier columns.
  - **Mobile (< 768px):** Navigation transitions to an off-canvas drawer; metric cards stack into single-column cards with `margin-mobile: 1rem` and compact internal padding.

## Elevation & Depth

Visual hierarchy does not rely on heavy, disorienting drop shadows. Depth is established through subtle tonal layers, low-opacity glass borders, and diffused light glows inspired by Flowdesk's signature dark UI.

### Spatial Layering Architecture
1. **Canvas Base (`#0B0F14`):** Foundational backdrop, zero elevation.
2. **App Shell / Sidebar (`#0B0F14` / `#0F1419`):** Divided by a crisp right-hand border (`1px solid #1E2633`).
3. **Card Container (`#151C24`):** Floats above the canvas with a `1px` border of `rgba(255, 255, 255, 0.07)`. It uses an extra-diffused, ambient shadow: `0 8px 32px -4px rgba(0, 0, 0, 0.45)`.
4. **Active & Hover Card Surfaces (`#1A222D`):** Lightens subtly on interaction, paired with an illuminated border accent (`rgba(0, 174, 255, 0.28)`) and a delicate cyan ambient back-glow: `0 0 24px -2px rgba(0, 174, 255, 0.08)`.
5. **Overlays & Modals (`#151C24` with Backdrop Blur):** Backdrops utilize `backdrop-filter: blur(16px)` over `rgba(11, 15, 20, 0.75)` with an elevated perimeter outline `rgba(255, 255, 255, 0.12)` and shadow `0 20px 48px -8px rgba(0, 0, 0, 0.7)`.

## Shapes

The design system employs a balanced `rounded-2xl` geometric signature for primary cards and content modules, contrasted against tighter micro-radii for inputs and pill-radii for indicators.

### Shape Geometry Rules
- **Cards & Data Modules:** Enforce `1rem` (16px / `rounded-2xl`) corner rounding, balancing modern aesthetics with screen space efficiency.
- **Interactive Controls (Inputs, Standard Buttons):** Standardized on `0.5rem` (8px / `rounded-md`) to ensure precise hit boundaries and high mechanical clarity in dense configuration tables.
- **Status Chips & Pills:** Apply pure full-radius caps (`rounded-full` / 9999px) for tags, tenant identifiers, and operational badges.
- **Logomark Geometry:** Vector silhouettes honor the fluid, interlocking Möbius curves of the original SVG mark, housed within standardized square containers with `0.75rem` (12px) curvature.

## Components

### Buttons
- **Primary Button:** Luminous gradient or solid accent (`#00AEFF` hovering to `#0284C7`), text `#0B0F14` (ultra-dark navy for high contrast) or pure white with `font-weight: 600`. Height `36px` (compact) or `42px` (standard). Padding: `0 16px`. Subtle inner top highlight `inset 0 1px 0 rgba(255, 255, 255, 0.25)`.
- **Secondary / Ghost Button:** Background `rgba(255, 255, 255, 0.04)`, border `1px solid rgba(255, 255, 255, 0.08)`, text `#F8FAFC`. On hover: surface becomes `#1A222D`, border transitions to `rgba(255, 255, 255, 0.16)`.
- **Icon Buttons:** Fixed `36x36px` with 18px SVG icons centered. Background matches secondary button specs.

### Status Chips (Pills)
- **Construction:** `height: 24px`, padding `0 10px`, `border-radius: 9999px`. Displays an aligned `6px` circular status indicator followed by uppercase or title-case text in `11px` (`label-sm`).
- **Variants:**
  - *Active:* Background `rgba(16, 185, 129, 0.12)`, text `#10B981`, border `1px solid rgba(16, 185, 129, 0.25)`.
  - *In Production:* Background `rgba(0, 174, 255, 0.12)`, text `#00AEFF`, border `1px solid rgba(0, 174, 255, 0.25)`.
  - *Confirmed:* Background `rgba(139, 92, 246, 0.12)`, text `#A78BFA`, border `1px solid rgba(139, 92, 246, 0.25)`.
  - *Awaiting Acceptance:* Background `rgba(245, 158, 11, 0.12)`, text `#FBBF24`, border `1px solid rgba(245, 158, 11, 0.25)`.
  - *Suspended:* Background `rgba(239, 68, 68, 0.12)`, text `#F87171`, border `1px solid rgba(239, 68, 68, 0.25)`.

### Cards & Metric Modules (KPIs)
- **Layout:** Standard padding `1.25rem` (20px). Top row features metric category title (`text-muted`, 12px) paired with an outline SVG icon in a 28px rounded glass badge.
- **Metric Value:** Displayed in 28px semi-bold tabular numerals (`#F8FAFC`), flanked by inline mini sparklines or percentage trend indicators (`+14% vs last cycle` in `#10B981` or `#EF4444`).

### Data Tables
- **Header:** Sticky row with background `#0F1419`, bottom border `1px solid #1E2633`. Typography: `11px` medium tracking, color `#64748B`.
- **Row Styling:** Minimum height `48px`, alternating hover fill (`#151C24` to `#1A222D`). Border-bottom `1px solid rgba(255, 255, 255, 0.04)`.
- **Cells:** Vertical centering with strict tabular alignment: text left-aligned, monetary and quantitative units right-aligned, status chips centered.

### Input Fields & Controls
- **Inputs:** Height `38px`, background `#0F1419`, border `1px solid #1E2633`, radius `8px`, typography `13px` `#F8FAFC`. Focus ring: `1px solid #00AEFF` with `0 0 0 3px rgba(0, 174, 255, 0.15)`.
- **Checkboxes & Radios:** `16x16px`, background `#0F1419`, border `1px solid #2A3649`. Checked state transitions to `#00AEFF` with a crisp white check vector icon.

### Iconography Rules
- Lucide-style, monoline 1.75px stroke SVG icons only. Pure SVG vector assets throughout navigation, table action menus, and metric cards. Emojis are strictly disallowed across all platform environments.
