1. Business profile

Open Settings and Bot settings. Add greeting, about text, hours, and website so the AI answers with your real information.

2. WhatsApp Cloud API

  1. In Meta Developer, open your WhatsApp app → API Setup.
  2. Copy Phone number ID and create a permanent System User access token.
  3. Paste them under WhatsApp API in Client-RaQ and save.
  4. Webhook URL: https://clientraq.com/webhook
  5. Verify token: the value from your server env WHATSAPP_VERIFY_TOKEN.
  6. Subscribe to messages. Send a test WhatsApp message to your business number.

3. Telegram (if included in your plan)

  1. Talk to @BotFather on Telegram → /newbot → copy the bot token.
  2. Add the token in company channel settings when available.
  3. Set webhook to your Client-RaQ Telegram endpoint (documented when Telegram is enabled on your plan).
